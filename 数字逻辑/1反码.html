核心概念二：循环进位 (End-Around Carry)

反码加法中，若最高位（符号位）产生进位，该进位绝不能丢弃，必须“绕回”加到最低位。下面以 +3 + (-2) 为例演示：

演示步骤
循环回卷 ↩
被加数 (+3) 0 0 1 1
加数 (-2反码) +1 1 0 1
首次相加 1 0 0 0 0
最高位进位回加 + 1
最终结果 (+1) 0 0 0 1

核心概念三：双零问题 (The Two Zeros)

反码最致命的缺陷之一：数值“零”在编码中占用了两个不同的位置，造成了编码浪费和硬件判零逻辑的复杂化。

正零 (+0)

在反码中，正零的表示与原码一致，所有数值位和符号位均为 0。

00000000
负零 (-0)

将正零“逐位取反”后，便得到了负零。它同样代表数值 0，但编码完全不同。

11111111
为什么这是个问题？ 在计算机硬件中，为了判断一个计算结果是否为0，CPU必须设计两套电路分别去匹配 00000000 和 11111111。这不仅浪费了一个宝贵的编码位置（导致8位反码只能表示 -127~127，而补码能表示 -128~127），还增加了芯片设计的复杂度。这也是为什么我们最终走向了补码。
